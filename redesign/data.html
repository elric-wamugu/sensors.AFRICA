Data · open by default

Open data. Take it, use it, publish with it.

sensors.AFRICA publishes open, real-time and historical air-quality data — PM2.5 and PM10 readings in µg/m³ — for African cities. Journalists chase leads with it, researchers model with it, and civic watchdogs hold polluters to account with it. Everything here is free to use: live widgets you can embed anywhere, a public API, and downloadable archives.

The API and the archives

Widgets are the front door. Behind them sit a public API for live queries and bulk archives for serious analysis.

Public API

Query readings, city by city

The sensors.AFRICA API serves current and recent air-quality readings by city, plus pointers to historical archives — the same data behind the maps and widgets, as clean JSON.

Using the data

Credit it, and it's yours

An open project should be easy to reuse responsibly. Here's how to attribute the data — and how it's produced in the first place.

Attribution & licence

sensors.AFRICA is an open project incubated by Code for Africa. The data is published openly for journalists, researchers and civic watchdogs to reuse — we ask only that you credit the source. The platform software is free and open source, released under the GNU GPL v3.0.

Suggested credit: "Air-quality data: sensors.AFRICA, a Code for Africa project · WHO Global Platform on Air Quality & Health."

How the data is produced

Readings come from low-cost, open-source sensors built on Luftdaten technology around the SDS011 particulate sensor. Citizens host them at homes, schools and offices; each node measures the air and streams its readings to the open platform over Wi-Fi or GSM.
